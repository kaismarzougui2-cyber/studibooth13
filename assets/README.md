# Dossier `assets/` — images du site

Déposez ici vos fichiers avec **exactement ces noms** (sinon les images ne
s'afficheront pas) :

| Fichier attendu | Utilisé pour |
| --- | --- |
| `logo.png` | Logo — affiché dans le hero de l'accueil **et** en favicon (toutes les pages) |
| `photobooth-classique.jpg` | Section Photobooth Classique (accueil + page Photobooth) |
| `photobooth-vintage.jpg` | Section Photobooth Vintage (accueil + page Photobooth) |
| `camera-360.jpg` | Section Cabine 360° (accueil + page 360 Booth) |

## Conseils
- Respectez les noms et extensions à l'identique (`.png` pour le logo, `.jpg`
  pour les photos). Si vos fichiers ont une autre extension, renommez-les.
- Logo : idéalement un PNG carré à fond transparent (≈ 512×512 px).
- Photos : format paysage, ≈ 1200×800 px, < 500 Ko chacune pour un site rapide.

Une fois les fichiers ajoutés ici et poussés (commit), les images apparaissent
automatiquement — aucune autre modification n'est nécessaire.
